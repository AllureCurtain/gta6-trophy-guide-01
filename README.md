Leonida Platinum is an offline, single-page trophy guide and tracker for Grand Theft Auto VI on PlayStation 5. It covers all 55 official trophies — one platinum, two gold, six silver and 46 bronze — with a plain-language guide for each one, a checklist that saves in your browser, filters by grade, state and missables, a spoiler toggle that hides story trophies until you earn them, progress export and import, and a six-stage platinum roadmap with a missables box. Everything runs locally: no network requests, no account, no tracking. The seven missable flags are inferred from the trophy descriptions, not playtested — the game is not out yet.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080/ in a browser.
